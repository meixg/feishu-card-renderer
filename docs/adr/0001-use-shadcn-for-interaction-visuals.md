# 交互视图采用 shadcn/ui 默认视觉

飞书 JSON 2.0 继续定义交互的值、表单、动作和上下文语义，交互视图则采用固定版本的 shadcn/ui `base-nova` 生成源码作为默认视觉事实来源，不再复刻飞书控件外观。renderer 只保留宿主作用域、类名前缀、portal、打包、卡片宽度和设备适配所需的集成布局，并将危险性、重要性和控件状态等协议视觉语义映射到最接近的 shadcn variant；协议内容布局不受此决定影响。

不提供旧飞书风格交互主题或双实现开关。shadcn 源码固定为仓库内已验证的快照，上游升级通过独立变更重新生成、比较并验证，而不自动覆盖本地适配。
