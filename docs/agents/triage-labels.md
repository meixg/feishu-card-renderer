# 分诊标签

工程技能使用以下五种标准分诊角色。本文件记录标准角色与当前仓库实际标签的对应关系。

| 标准角色 | 当前仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交由自动化代理实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某种分诊角色时，必须使用表中对应的仓库标签。若仓库以后更改标签命名，只需修改本表右侧的“当前仓库标签”列。
