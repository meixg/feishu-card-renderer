# 领域文档

本文件规定工程技能探索代码库时如何读取和使用领域文档。

## 探索前读取

- 若根目录存在 `CONTEXT.md`，读取其中的领域术语和上下文。
- 若根目录存在 `CONTEXT-MAP.md`，根据其索引读取与当前任务有关的上下文文档。
- 阅读 `docs/adr/` 中与当前工作区域相关的架构决策记录。

文件不存在时静默继续，不应仅因缺少这些文件而要求提前创建。相关文档由领域建模流程在实际形成术语或决策后按需创建。

## 文档布局

本仓库采用单上下文布局：

```text
/
├── CONTEXT.md
├── docs/
│   └── adr/
└── src/
```

`CONTEXT.md` 记录领域术语和共同语言，`docs/adr/` 记录架构决策。

## 使用统一术语

Issue 标题、重构建议、假设和测试名称应使用 `CONTEXT.md` 中定义的术语，避免改用其明确排除的同义词。

若所需概念尚未出现在术语表中，应判断这是偏离现有语言，还是需要通过领域建模补充的真实空白。

## 标明 ADR 冲突

若拟议变更与现有 ADR 冲突，必须明确指出冲突，不得静默覆盖既有决策。
